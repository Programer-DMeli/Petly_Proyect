# seeds/

Datos de demostración para desarrollo local (albergues, mascotas, usuarios de prueba).

Reglas:

- Sin datos personales reales, sin contraseñas reales y sin fotografías privadas.
- Los archivos que se suban a Git son CSV/JSON de ejemplo, nunca volcados de la base real.
- Los seeds no sustituyen las migraciones de Django ni el historial de Flyway.

Cuando existan tablas de negocio, aquí se documentará el orden de carga y los comandos para aplicarlas.

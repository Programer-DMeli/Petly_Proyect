# Imagen de fondo de la portada

La imagen de portada se llama `portada.png`.

Ruta: `web/public/images/portada.png`.

Vite sirve los archivos de `public/` desde la raíz del sitio, así que no hace falta importar la imagen en el código. Si el archivo todavía no existe, la portada conserva el fondo verde.
